## Cost Optimization Tips

1. **Use SD XL locally** — eliminates $50-100/video Midjourney cost
2. **Use Ollama locally** — eliminates API costs for script generation
3. **Batch pipeline runs** — maximize GPU utilization
4. **Cache research** — reuse briefs for similar topics
5. **Start with DFW + STM** — lowest cost to entry, fastest YPP path
