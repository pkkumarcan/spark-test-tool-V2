# X75 — Release Checklist

**Purpose:** Pre-publish checklist, AI disclosure, SEO optimization, and quality gates.  
**Created:** 2026-07-09 (V3 — YouTube compliance + vidIQ SEO)  
**Estimated time:** 10 minutes

---

## Pre-Publish Checklist

### Content Quality
- [ ] Script approved at Step 4 (human review)
- [ ] Voiceover matches script timing
- [ ] All keyframes present and correct
- [ ] No black frames or visual glitches
- [ ] Audio syncs with visuals (offset < 80ms)
- [ ] Outro card displays correctly
- [ ] Total duration matches script timing

### Technical Quality
- [ ] Export at 1920x1080, H.264, 15-20 Mbps
- [ ] Audio: AAC 320kbps
- [ ] File size reasonable (500MB-2GB for 5-15 min)
- [ ] No encoding artifacts
- [ ] Thumbnail is 1280x720, readable at small size

### SEO Optimization
- [ ] Title scored with vidIQ (target: 70+ score)
- [ ] Description includes timestamps + affiliate links
- [ ] Tags: top 15 by vidIQ overall score
- [ ] Thumbnail has 3-5 words max, high contrast
- [ ] Category set correctly (e.g., "Science & Technology")

### YouTube Compliance
- [ ] "Contains AI-generated content" toggle ENABLED
- [ ] No false claims about AI visuals being real footage
- [ ] Health content (PKP): disclaimer in description AND verbally
- [ ] Finance content (GDB): disclaimer in description
- [ ] No deepfakes of real people
- [ ] Not publishing more than 3-4 videos/day per channel

### Channel Consistency
- [ ] Visual style matches channel brand
- [ ] Voice matches channel tone
- [ ] Title format follows channel template
- [ ] Thumbnail follows channel template

## Title Optimization (vidIQ)

### Title Scoring Process
1. Generate 3 title variations
2. Score each with vidIQ title scorer
3. Select highest-scoring title
4. Verify primary keyword is in first 60 characters

## Tag Strategy

### Tag Categories
1. **Primary keyword** (1-2 tags): Exact match to title keyword
2. **Secondary keywords** (3-5 tags): Related search terms
3. **Long-tail keywords** (3-5 tags): Specific phrases with lower competition
4. **Channel tags** (2-3 tags): Channel name + niche

### Tag Limits
- YouTube allows up to 500 characters total
- Use all available space
- Order by importance (first tags weighted more)

## Post-Publish Actions

### Immediately After Publishing
- [ ] Share on relevant social media
- [ ] Add to channel playlist
- [ ] Set end screen (next video + subscribe)
- [ ] Add cards (related videos)
- [ ] Pin a comment with key takeaway

### 24 Hours After
- [ ] Check CTR (target: 3%+)
- [ ] Check retention (target: 40%+)
- [ ] Respond to early comments
- [ ] Note any issues for future improvement

### 7 Days After
- [ ] Review full analytics
- [ ] Compare to channel average
- [ ] Flag for thumbnail A/B test if CTR <3%
- [ ] Flag for script review if retention <40%
- [ ] Identify what worked → brief similar video

## AI Content Disclosure (YouTube 2026)

### Required Disclosure
- [ ] Enable "Contains AI-generated content" in YouTube Studio
- [ ] This applies to: AI voiceover, AI-generated images, AI-written scripts
- [ ] YouTube does NOT demonetize AI content (as of 2026)

### What Requires Disclosure
- AI-generated visuals that could be mistaken for real footage
- AI voice cloning of real people (requires consent)
- Significantly altered or synthetic content

### What Does NOT Require Disclosure
- AI-written scripts (no rule against this)
- AI-generated music (if you own rights)
- AI voiceover (common and accepted)
- Stock footage manipulation

### What Risks Demonetization
- Fully automated channel with no human oversight
- Repetitive, low-effort content
- Medically inaccurate health claims (PKP)
- Financial advice without disclaimers (GDB)
