## Content Calendar Template

### Monthly Planning (Per Channel)

```
Week 1:
  - Monday: Topic research + script generation
  - Tuesday: Approval + voiceover
  - Wednesday: Visual generation + assembly
  - Thursday: Thumbnail + metadata
  - Friday: Publish + promote

Week 2:
  [Same pattern, different topic]

Week 3:
  [Same pattern]

Week 4:
  - Review analytics
  - Plan next month's topics
  - Batch research for efficiency
```

### Weekly Checklist

- [ ] Research 4-6 topic ideas per channel
- [ ] Generate scripts for top 2
- [ ] Get approval on scripts
- [ ] Produce voiceover
- [ ] Generate keyframes
- [ ] Assemble video
- [ ] Create thumbnail
  - [ ] Write metadata (title, description, tags)
  - [ ] Schedule publish
- [ ] Respond to comments on published videos
- [ ] Review analytics from last week

## Seasonal Considerations

| Quarter | CPM Impact | Strategy |
|---------|-----------|----------|
| Q1 (Jan-Mar) | Lowest CPMs | Focus on building catalog, not revenue |
| Q2 (Apr-Jun) | Moderate | Start monetization efforts |
| Q3 (Jul-Sep) | Growing | Scale production |
| Q4 (Oct-Dec) | Highest CPMs | Maximum production, capitalize on holiday ad spend |

**Best time to launch new channels:** Q1 (build catalog before Q4 peak)
